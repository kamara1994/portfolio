# Joseph Allan Kamara — Portfolio

Next.js 14 · TypeScript · Tailwind CSS · Framer Motion · three.js. Auto-deploys to Vercel from `main`.

```bash
npm install
npm run dev   # http://localhost:3000
```

- Projects: `data/projects.ts`
- Skills, certs, experience: `data/index.ts`
- Static assets: `public/` (resume, profile photo, screenshots, cert images)
